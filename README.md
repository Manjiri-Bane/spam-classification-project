This project implements a basic spam classification system that identifies whether a message is spam or not. It uses two approaches:

Python (Naive Bayes with Scikit-learn): The Python version uses the Naive Bayes algorithm, a machine learning technique, to classify messages based on training data. It converts the messages into word frequency vectors and trains the model to predict whether a message is spam or not.

C Program (Custom Spam Classifier): The C version mimics a simple machine learning model by counting word occurrences in spam and non-spam messages. It uses Bayes' theorem to classify new messages based on the probability of word occurrences in spam and non-spam categories.

Both versions aim to automatically classify text messages as either "spam" or "not spam," helping to filter unwanted messages
